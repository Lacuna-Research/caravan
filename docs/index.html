A native macOS IRC client, loosely inspired by the good ol’ days of mIRC.

mIRC got a great deal right in 1995 and most of it is still right. This is that client, rebuilt natively for macOS — a client that treats IRC as a protocol rather than hiding it behind a chat metaphor.

why another IRC client

IRC as a protocol, not a metaphor

/debugThe protocol is not hidden

A status window shows raw traffic in both directions, /debug streams it to a window or a file, and every unrecognized line still lands somewhere visible instead of being silently dropped.

sojuBouncer-first

soju is a primary target, not an afterthought: bouncer-networks and chathistory land in stage 2, not stage 3, with backfill de-duplicated against local logs.

KeychainCredentials handled like credentials

Redaction happens on insert into the trace buffer, never at export, so a password is never resident anywhere it could be scraped later. Secrets live in the macOS Keychain — never in a file.

^C 0–98mIRC formatting, both appearances

Bold, italic, underline, strikethrough, monospace, reverse, and the full 99-colour palette — with a separate luminance-adjusted table for dark backgrounds, because inverting white and black leaves the other fourteen unreadable.

XDGNothing written to the source tree

Settings, logs and caches follow XDG paths. The config file is plain text, hand-editable, and only ever holds what you actually changed — your comments survive the app writing it back.

0 depsNo dependency chain

One SwiftPM package, four modules, nothing vendored but test fixtures. Swift 6 strict concurrency throughout, SwiftUI shell with AppKit where AppKit is genuinely better — the scrollback is an NSTextView.

SASLModern auth on an old protocol

PLAIN, EXTERNAL (CertFP) and SCRAM-SHA-256, NickServ fallback, trust-on-first-use for TLS — and a refused certificate is a terminal answer, never a prompt that re-asks until you give in.

stage 3Scripting without the malware vector

JavaScript via JavaScriptCore rather than mIRC’s language. A bare JSContext has no require, fetch or filesystem at all — capabilities are granted, not restricted — and Safari Web Inspector attaches for real breakpoints.

architecture

Four modules, one app, dependencies point one way

IRCProtocol has no I/O, no Foundation, no Darwin APIs — nothing but the standard library. CI builds and runs its test suite on Linux, so the moment someone reaches for AppKit in there, a job fails. The rule is mechanical, not a comment in a file.

roadmap

Four stages, each ending somewhere usable

Full detail in PLAN.md; the prompt queues in STAGE2-PROMPTS.md are authoritative for scope and status.

Stage 1 — connect, join, chat

11/11 prompts · complete

TLS, registration and reconnect with backoff · full IRCv3 message parsing against the community corpus · channel and user state with a rank-ordered nick list · the core commands · a status window showing raw traffic · plain-text config you can edit by hand. You can idle in a channel on Libera and hold a conversation.

Stage 2 — a mIRC daily driver

3/17 prompts · in progress

Formatting codes and the 99-colour palette ✓ · a multi-line input that authors codes and completes what you type ✓ · capability negotiation and SASL ✓ · next: multi-network and the bouncer, queries and CTCP, activity states and a ⌘K switcher, the full command set, mode tracking, options, logging with chathistory de-duplication, highlights and notifications, flood protection. Done when you would use this instead of your current client.

Stage 3 — mIRC parity

planned

DCC with resume and passive mode · scripting in JavaScript with declarative aliases and popups for the one-liner cases · themes over the format-table seam · identd, proxies, Tor · user levels · soju extras · full-text history search.

Stage 4 — polish and release

planned

Accessibility and localization · performance work on the scrollback pipeline · Developer ID signing and notarization · distribution as a Homebrew cask from our own tap · a mirc.ini settings importer for anyone migrating.

from the build log

Every decision written down

BUILD-LOG.md is append-only: it records what was decided and what was rejected and why — including the mistakes, which stay in the log alongside their corrections rather than being quietly edited away. A condensed timeline:

2026-08-04decision

Scrollback will be AppKit, not SwiftUI

Before any code, the chat scrollback was settled as an AppKit NSTextView — a pure SwiftUI list degrades badly past a few thousand rich-text rows. The same session fixed the security posture: credentials are redacted the moment they enter the trace buffer, never at export.

2026-08-04decision

Every project rule becomes a failing check

A review found seven weaknesses in the project’s tracking, all with one root cause: every rule was a promise audited by the person who made it. The fix was a script that fails the build on a stale doc, an edited log line, or an undeclared dependency — important conventions get made mechanical, not written more emphatically.

2026-08-04decision

Credentials go in the Keychain, full stop

A config file is readable by any process and lands unencrypted in backups — and TLS client certificates must be Keychain items anyway, so splitting stores made no sense. The same day, the zero-dependency rule quietly killed GRDB: persistence wraps the system SQLite directly.

2026-08-04decision

MQTT rejected: IRC is one ordered stream

The idea of an MQTT broker between bouncer and client died on a single fact: IRC’s state machine depends on one totally-ordered stream, and MQTT only orders within a topic. Fan out and you get rare, unreproducible state corruption; use one topic and it is a worse TCP with a broker in the middle.

2026-08-04decision

Scripting is JavaScript, not the mIRC language

JavaScriptCore ships with macOS, costing zero dependencies. Verified before choosing: a bare JSContext exposes no network, no filesystem, no ambient authority at all — the sandbox is the default state, not a restriction bolted on afterwards.

2026-08-04milestone

Parser corpus passes; CRLF is one Character

The message parser landed with the full community parser-tests corpus passing — which caught a genuinely nasty Swift gotcha: Swift treats a CR LF pair as a single Character, so a character-by-character escaping loop silently let line terminators through. Protocol code now iterates raw unicode scalars.

2026-08-04decision

Homebrew cask beats the App Store

DCC needs incoming connections and identd wants port 113, both painful-to-impossible in the App Store sandbox. A happy accident surfaced too: XDG paths mean clean uninstall is a three-line zap stanza instead of a scavenger hunt through ~/Library.

2026-08-05milestone

First real connection — and a wrong theory

Transport and session registered live against Libera.Chat over TLS for the first time. Careful measurement overturned the previous day’s claim: a refused connection fails in milliseconds — it’s an unroutable address that hangs forever with no error, which is why the client owns its own connect deadline.

2026-08-05decision

A 50,000-line benchmark picks the text engine

A benchmark appended 50,000 lines and scrolled every viewport: TextKit 1 used 25 MB where TextKit 2 used ten times more. A follow-up honestly re-ran the comparison fairly, concluded the choice was safe rather than forced — and the engine remains a one-line change to revisit.

2026-08-05surprise

The live run finds what tests can’t

The first multi-channel build passed all 254 unit tests, then failed in the first minute of real use: switching channels blanked the scrollback, and one channel’s messages appeared under another’s topic bar. Both were view-lifecycle behaviour no headless test could see — so every unit of work now ends with a live run against a real network.

2026-08-05surprise

Shift+Return is indistinguishable from Return

The multi-line input box could not be built as designed: AppKit delivers Shift+Return through the exact same selector as plain Return, so every attempt at a soft line break sent the message instead. The fix reads modifiers through an injectable seam — bought, as the log puts it, “with a bug that shipped once”.

2026-08-05decision

Menlo wins the font shootout, by measurement

A script measured glyph coverage across monospace fonts: SF Mono is missing eleven of the forty-four classic CP437 art characters, which CoreText silently substitutes at up to 1.8× cell width — wrecking ASCII art. Menlo covers all of them, and the measurement became a permanent regression test.

2026-08-05milestone

Stage 1 complete: 372 tests, zero dependencies

Eleven prompts, one PR each, a working IRC client — connect, join, chat, commands, debug console — with zero external packages. The retrospective’s sharpest finding: all three defects that escaped to live runs were about what the user sees, never about state.

2026-08-06surprise

One nick palette was arithmetically impossible

Colouring nicknames accessibly in both appearances has no single-palette solution — the contrast maths proves no colour clears 4.5:1 against both near-white and near-black. So a nick’s hash picks a hue, the appearance picks its lightness, and a test named oneTableWasImpossible records the proof.

2026-08-06surprise

Screenshots lie; sample the pixels

A one-line attribute conversion had been silently discarding every colour, underline and link before they reached the screen — every unit test asserted the renderer’s output, which was correct, while the text storage sat empty. Verification switched from eyeballing screenshots to sampling pixel values.

2026-08-06surprise

Refusing a certificate has to mean no

The first GUI run of the TLS trust prompt caught it within the hour: declining a self-signed certificate triggered a reconnect that re-presented the same dialog every few seconds. A prompt that won’t take no for an answer trains people to click yes — refusal is now terminal, as is a rejected password.

how this gets built

The rules are machine-checked

One prompt per branch, one PR, squash-merged once CI is green. main is protected: four required checks, no force-pushes, admins not exempt. The interesting part is that the project’s own conventions are enforced by a script that runs as a pre-commit hook and in CI, and fails on:

  • An instruction file over 100 lines. The cap forces pruning instead of accretion — and it is not to be raised.
  • Any edit to an existing build-log line. The log is append-only; corrections are new entries, so mistakes stay visible next to their fixes.
  • A code change with no build-log entry. Deviations, surprises and measurements get recorded when they happen, not reconstructed later.
  • A progress badge that disagrees with the status line. A stale badge is worse than none — it is confidently wrong.
  • A carry-forward note that outlived its prompt. A note that survives the work it was addressed to is a note that was never consumed.
  • An undeclared dependency. Adding one requires a written decision — and an edit to the very check that would otherwise fail.
  • Darwin APIs in the protocol layer. CI builds IRCProtocol on Linux, so purity is a build result, not a code-review opinion.

building

Clone it, make it

Requires Xcode 26+ on macOS 15+.

$ git clone https://github.com/Lacuna-Research/caravan.git
$ cd caravan
$ make hooks   # install the pre-commit hook — once, after cloning
$ make all     # build, test, lint, docs check, app

Where your data lives

Nothing is ever written inside the source tree — not even under a gitignored path. Config paths are public API.

WhatWhere
Settings$XDG_CONFIG_HOME/caravan/caravan.conf — plain text, hand-editable
Logs, scrollback$XDG_DATA_HOME/caravan/
Caches$XDG_CACHE_HOME/caravan/
Passwords, client certsmacOS Keychain — never a file
